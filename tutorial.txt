Front end code ReactJS, tham khảo https://www.youtube.com/watch?v=jbfuzcrfjqQ
- Cài NodeJS + npm
- Cài react-slick: npm install react-slick --save
npm install slick-carousel
-Cd frontend chạy: npm start 
- lucide-react
- recharts
Backend package: npm install nodemon express mongoose dotenv
    - install thêm: npm install jsonwebtoken cors bcryptjs
    - trước đó phải có tài khoản mongodb, tải mongodb compass để kết nối
    - chạy backend: node index.js (trước)
    - chạy frontend: npm start (sau)
