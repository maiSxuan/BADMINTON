Front end code ReactJS, tham khảo https://www.youtube.com/watch?v=jbfuzcrfjqQ
- Cài NodeJS + npm

Backend package: npm install nodemon express mongoose dotenv 
    - nodemon dùng cho chạy server: nodemon server.js
    - moongoose dùng cho xử lí database lưu vào mongodb
    - Tạo cluster trên atlas (cloud) của mongodb
    - Tạo một file .env để lưu đường dẫn vd MONGO_DB = mongodb+srv://{tài khoản}:{mật khẩu}m@cluster0.y4bqdbq.mongodb.net/ rồi vào server.js
    - (Tạo database bằng mongodb compass connect vào mongodb+srv://{tài khoản}:{mật khẩu}m@cluster0.y4bqdbq.mongodb.net/ là đc)
    - Connect bằng mongoose.connect (`${process.env.MONGO_DB}`)
